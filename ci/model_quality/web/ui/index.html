Inference smoke Required

Prestarted allowlisted container + your existing serve script (no rewrite needed). The pipeline wraps it: injects the quantized model path as env (model_dir / MODEL_DIR / output_dir) and reports_dir, launches your script, waits for 127.0.0.1:<port>, sends a probe, and records PASS/FAIL. So an env-style script like MODEL_DIR=${model_dir:-…} works unchanged. Set the Port your service listens on (varies per model is fine). Arguments are optional extra argv forwarded to your script.

Quality evaluation Required

Pick a tool and dataset preset. The served model is reached inside the smoke container, so no URL is needed. A custom argv override is optional.
